## 设计稿 v2（design/v2/）—— 按简报出的第一版
`index.html` + `app.css`(≈640 行) + `app.js`(≈140 行)，三页共用一份 HTML，可交互：切页 / 主题三态 / P1 行展开长跑。

**自检结论**：`inspect.mjs --app` 1 FAIL + 1 WARN，两条都是刻意保留，不是缺陷：
- `font-not-dealt`：简报 §6.1 明确删掉自托管 Inter 走系统字体栈，属有意为之，**不要为了消警去装 Inter**。
- `kpi-size`（总分 64px）：总分是产品唯一答案，需要一个压倒性的数字，保持。

**这轮修掉的真实问题（供改现有代码时复用）**：
1. **窄屏塌陷**：`.app` 是 `232px + 1fr` 网格，390px 下只剩 158px 给内容，文字逐字换行。已在 860/700 两档把侧栏折成顶部横条、行改多行堆叠。
2. **徽章列宽不定**：`auto` 列让「可达 · 需 Key」把后面数值列顶歪。改成固定 `92px`，六行数值才对齐。
3. **长跑时间线像坏图**：42s/1800s 意味着 97% 是空白，读起来像图表挂了。加 `--bad-wash` 死区色块 + HTML 绝对定位标注「29 分 18 秒 · 0 字节」，空白本身变成结论。
4. **亮色下状态带失色**：10% wash 在白底几乎看不见。wash 提到 19–22%，同时把徽章拆出 `--*-soft`（7%）单独一档，否则药丸底色一重就把彩色小字压到 4.5:1 以下。
5. **`--accent` 兼两职不行**：白字压 `#007aff` 只有 4.0:1。拆成 `--accent`（文字/图标）与 `--accent-fill`（按钮底），暗色下按钮用 `#0a6fd8`。
6. 亮色 `--good` 从 `#248a3d`（4.39:1）压到 `#1f7d36`（5.19:1）。

**测量方法教训**：`inspect.mjs` 产出的 jpg 是高 DPR 合成图，肉眼看会出现"内容只占左边一小条"的错觉。判断布局真伪要用 CDP 量 `getBoundingClientRect` + `scrollWidth`，别靠截图目测。

## 设计稿 v3（design/v3/）—— 粘土拟态 claymorphism

用户改方向：① 总评设置与分评设置必须分开（整体设置 vs 单项设置）；② UI 换粘土拟态（附完整 STYLEKIT 规范）。v3 与 v2 并存，不覆盖。

`index.html`(193) + `app.css`(671) + `app.js`(303)，`shots/` 11 张交付图。

**信息架构落点（需求①的实体）**
- `设置` 页只放六项共用项：代理来源 / 代理地址 / 单请求超时 / 并发 / 流量预算。
- `分评` 每行挂「这项设置」，展开 `.pset` 内凹面板；`own` 有键=已覆盖，无键=跟随整体（`valOf()` 兜底到 `GLOBAL`）。
- 「单次时长」「长时稳定性 30 分钟」**不在整体设置里**，只属于 P1 —— 避免同名参数两处可改、用户不知哪个生效。
- 长跑开关开启后锁 1800s/1024MB/单流并禁用另外三个输入框。

**这轮修掉的真问题**
1. **移动端分评行被拆成 3–4 行堆叠**，单行 ≈200px，一屏只容 3 项半。改成 3 行紧凑区（name+badge / value / act 右对齐），数值不再折行。
2. **面板 5 个字段 `auto-fit` 挤成一行**，宽度各异、「已覆盖」标记把控件顶歪。改 2 列网格 + label 行内嵌标记 + 长时开关独占整行（顶部 1px 分隔）。
3. **卵石宽度语义无解释**：`--w` 承载耗时但用户读不出来。加 `.pebbles-cap`；窄屏 flex 被 `min-width` 夹平后宽度不再表意，用 `.cap-wide/.cap-narrow` 换措辞，不让说明说谎。
4. **「40%」歧义**（是得分还是权重）→ 改「权重 40%」。
5. **文案数字错**：运行参数说明写「这四项」，实际只有三项。
6. 分评行数值下方挂 `<small>` 证据摘要，需 `.row-value small` 单独设样式。

**刻意偏离规范（交付时须说明，不许偷偷改）**
- 按钮 `text-white` 压 `pink-300/400` 仅 2.6:1 → 压深到 `#db2777→#be185d`。
- `text-pink-400` 白底 3.0:1 → 弱化文字用 `--ink-3 #9c4f70`。
- 状态色不用糖果色，用语义绿 `#0b7a52` / 琥珀 `#96540a` / 陶土红 `#a32a2a`（诊断结论必须一眼分好坏）。
- 规范 `hover:translate-y-1`（向下）与「悬停上浮」语义相反 → 统一 `translateY(-4px)`。
